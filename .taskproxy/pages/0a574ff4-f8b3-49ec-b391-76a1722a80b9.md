### Testing

<webui-page-segment>

Backend tests are Rust tests. 

Run `trunk build` once first on a new checkout, because the tests embed `dist/`.

```pwsh
trunk build
```

Run Backend Tests

```pwsh
cargo test -p taskproxy
```

UI tests use [Playwright](https://playwright.dev) and need no running app, since they serve the frontend straight from the repo and stand in for the backend. They do load the shared Web UI components from cdn.myfi.ws, so they need network access.

```pwsh
npm install
```

On Linux the tests use `/usr/bin/chromium` if it exists, so the second command can be skipped. 

```pwsh
npx playwright install chromium
```

Run everything against the source files. Use this while working 

```pwsh
npm test
```

Open the interactive runner, with watch mode and a timeline for each test 

```pwsh
npm run test:ui
```

Run everything against the `.min.js` files. Use this before pushing

```pwsh
npm run test:min
```

Open the last report, with a screenshot and trace for each failure 

```pwsh
npm run test:report
```

Run one file

```pwsh
npx playwright test tests/components/git-manager.spec.mjs
```

Run tests by name

```pwsh
npx playwright test -g "commit"
```


</webui-page-segment>
