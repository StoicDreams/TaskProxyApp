# Test for Deployment

<webui-page-segment>

Run everything against the `.min.js` files. Use this before pushing

```pwsh
npm run test:min
```

Show Last Report

```pwsh
npx playwright show-report
```

</webui-page-segment>

#### Publish

<webui-page-segment>

Minify

```pwsh
./PowerShell/Minify.ps1
```

Screenshots

```pwsh
./PowerShell/screenshots.ps1
```

Patch Update

```pwsh
./PowerShell/IncrementVersion.ps1
```

Minor Update

```pwsh
./PowerShell/IncrementVersion.ps1 -minor
```

Major Update

```pwsh
./PowerShell/IncrementVersion.ps1 -major
```
