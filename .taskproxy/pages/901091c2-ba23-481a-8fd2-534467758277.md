# Test for Deployment

<webui-page-segment>

Run every test, unit and browser, against the minified files, as CI does. Use this before pushing

```pwsh
npm run test:min
```

Show Last Report

```pwsh
npx playwright show-report
```

</webui-page-segment>

#### Publish

<webui-page-segment>

Minify

```pwsh
./PowerShell/Minify.ps1
```

Screenshots

```pwsh
./PowerShell/screenshots.ps1
```

Patch Update

```pwsh
./PowerShell/IncrementVersion.ps1
```

Minor Update

```pwsh
./PowerShell/IncrementVersion.ps1 -minor
```

Major Update

```pwsh
./PowerShell/IncrementVersion.ps1 -major
```

Run this before each publish.

```pwsh
$env:PATH = "$HOME/.cargo/bin:$HOME/.local/bin:" + $env:PATH
./PowerShell/Publish.ps1
```

</webui-page-segment>
