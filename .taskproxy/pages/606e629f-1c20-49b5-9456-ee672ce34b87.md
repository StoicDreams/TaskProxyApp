### Before you start

<webui-page-segment>

This project is a Tauri app. Its Rust code is in `src-tauri`, so you need Rust and the platform's build tools before it will run. Publishing also needs Node.js, npm, trunk, and a Playwright browser. Run the blocks below in order, using the Run button on each one.
Each block is a PowerShell 7 script. Task Proxy runs it in the project folder and shows its output in the Terminal Manager. Answer any prompts there.

You need PowerShell 7 before the first block can run: `brew install --cask powershell` on macOS, `winget install --id Microsoft.PowerShell` on Windows, or the package from the PowerShell site on Linux.

</webui-page-segment>

### Install build tools

<webui-page-segment>

**macOS:** Installs the Xcode Command Line Tools if they are missing. If the installer opens, finish it, then run this block again.

```pwsh
$ErrorActionPreference = 'Stop'
if ($IsMacOS) {
    xcode-select -p *> $null
    if ($LASTEXITCODE -ne 0) {
        xcode-select --install
        Write-Host 'Finish the Xcode Command Line Tools installer, then run this block again.'
    }
    else {
        Write-Host 'Xcode Command Line Tools are installed.'
    }
}
```

**Windows:** Installs the Visual Studio C++ build tools that Rust needs to link programs. This can take a while and may download several GB.

```pwsh
$ErrorActionPreference = 'Stop'
if ($IsWindows) {
    winget install --id Microsoft.VisualStudio.2022.BuildTools --exact --accept-package-agreements --accept-source-agreements --override '--wait --passive --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended'
}
```

**Linux:** Install the WebKit and GTK development packages that Tauri needs. Use your distribution's package manager. On Debian or Ubuntu, that is `libwebkit2gtk-4.1-dev`, `libgtk-3-dev`, `libayatana-appindicator3-dev`, and `librsvg2-dev`.

</webui-page-segment>

### Install Rust

<webui-page-segment>

This block installs `rustup`, the Rust tooller, if it is not already on this machine. It uses winget on Windows and the official `rustup-init` on macOS and Linux.

```pwsh
$ErrorActionPreference = 'Stop'
$toolchain = 'stable'

if (Get-Command rustup -ErrorAction SilentlyContinue) {
    Write-Host 'rustup is already installed.'
}
elseif ($IsWindows) {
    winget install --id Rustlang.Rustup --exact --accept-package-agreements --accept-source-agreements
}
else {
    $isArm = [System.Runtime.InteropServices.RuntimeInformation]::OSArchitecture -eq 'Arm64'
    if ($IsMacOS) {
        $triple = if ($isArm) { 'aarch64-apple-darwin' } else { 'x86_64-apple-darwin' }
    }
    else {
        $triple = if ($isArm) { 'aarch64-unknown-linux-gnu' } else { 'x86_64-unknown-linux-gnu' }
    }
    $installer = Join-Path ([System.IO.Path]::GetTempPath()) 'rustup-init'
    Invoke-WebRequest -Uri "https://static.rust-lang.org/rustup/dist/$triple/rustup-init" -OutFile $installer
    chmod +x $installer
    & $installer -y --default-toolchain $toolchain --profile default
}
```

</webui-page-segment>

### Configure Rust

<webui-page-segment>

This block adds Cargo's bin folder to this session's PATH, installs the toolchain, and adds the `clippy` and `rustfmt` tools. Open a new terminal after the install if `rustup` is not found.

```pwsh
$ErrorActionPreference = 'Stop'
$toolchain = 'stable'

$cargoBin = Join-Path (Join-Path $HOME '.cargo') 'bin'
if (-not (($env:PATH -split [System.IO.Path]::PathSeparator) -contains $cargoBin)) {
    $env:PATH = "$cargoBin$([System.IO.Path]::PathSeparator)$env:PATH"
}

rustup toolchain install $toolchain
rustup default $toolchain
rustup component add clippy rustfmt
rustup update $toolchain

rustc --version
cargo --version
```

</webui-page-segment>

### Install Node.js and npm

<webui-page-segment>

Publish runs `npm ci` to install the test tools, and `npm run test:min` to run the UI tests, so npm is required. This block installs Node.js 22 with Homebrew on macOS and winget on Windows. Node.js is also on the [Node.js website](https://nodejs.org) for Linux.

```pwsh
$ErrorActionPreference = 'Stop'
# Homebrew and Node.js from Homebrew are not on the PATH of an app started from the desktop, so add their folders.
foreach ($folder in '/opt/homebrew/bin', '/opt/homebrew/opt/node@22/bin', '/usr/local/bin') {
    if ((Test-Path $folder) -and -not (($env:PATH -split [System.IO.Path]::PathSeparator) -contains $folder)) {
        $env:PATH = "$folder$([System.IO.Path]::PathSeparator)$env:PATH"
    }
}
if (Get-Command npm -ErrorAction SilentlyContinue) {
    Write-Host "npm $(npm --version) is already installed."
}
elseif ($IsWindows) {
    winget install --id OpenJS.NodeJS.LTS --exact --accept-package-agreements --accept-source-agreements
}
elseif ($IsMacOS) {
    brew install node@22
    Write-Host 'If npm is still not found, open a new terminal, or add /opt/homebrew/opt/node@22/bin to your PATH, then run this block again.'
}
else {
    Write-Host 'Install Node.js 22 or newer with your package manager, or from https://nodejs.org, then run this block again.'
}
```

</webui-page-segment>

### Install Rust build tools

<webui-page-segment>

This block adds the wasm target that the frontend is built for, and installs `trunk`, which builds the frontend into `dist`, and `tauri-cli`, which runs the app in development. Publish builds `dist` with `trunk build` when it is missing. Installing `tauri-cli` can take a long time, since Cargo compiles it.

```pwsh
$ErrorActionPreference = 'Stop'

$cargoBin = Join-Path (Join-Path $HOME '.cargo') 'bin'
if (-not (($env:PATH -split [System.IO.Path]::PathSeparator) -contains $cargoBin)) {
    $env:PATH = "$cargoBin$([System.IO.Path]::PathSeparator)$env:PATH"
}

rustup target add wasm32-unknown-unknown
if (-not (Get-Command trunk -ErrorAction SilentlyContinue)) { cargo install --locked trunk }
if (-not (Get-Command cargo-tauri -ErrorAction SilentlyContinue)) { cargo install --locked tauri-cli }
trunk --version
cargo tauri --version
```

</webui-page-segment>

### Install test tools

<webui-page-segment>

This block installs the npm packages the tests use, then the Chromium browser that Playwright runs the browser tests in. Run it after the Node.js block. It takes a few minutes, since Chromium is large.

```pwsh
$ErrorActionPreference = 'Stop'
foreach ($folder in '/opt/homebrew/bin', '/opt/homebrew/opt/node@22/bin', '/usr/local/bin') {

```

### Install ffmpeg for the website media (optional)

<webui-page-segment>

Only needed to record the website's images and videos with `PowerShell/screenshots.ps1`, which Publish runs unless it is skipped. The build needs the `libx264` and `libwebp` encoders, which the Homebrew and winget builds include. The recordings also need the Stoic Dreams website checkout beside this project. Publish with `-SkipScreenshots` if you do not have it.

```pwsh
$ErrorActionPreference = 'Stop'
foreach ($folder in '/opt/homebrew/bin', '/opt/homebrew/opt/node@22/bin', '/usr/local/bin') {
    if ((Test-Path $folder) -and -not (($env:PATH -split [System.IO.Path]::PathSeparator) -contains $folder)) {
        $env:PATH = "$folder$([System.IO.Path]::PathSeparator)$env:PATH"
    }
}
if (Get-Command ffmpeg -ErrorAction SilentlyContinue) {
    Write-Host 'ffmpeg is already installed.'
}
elseif ($IsWindows) {
    winget install --id Gyan.FFmpeg --exact --accept-package-agreements --accept-source-agreements
}
elseif ($IsMacOS) {
    brew install ffmpeg
}
else {
    Write-Host 'Install ffmpeg with your package manager, built with libx264 and libwebp, then run this block again.'
}
```

</webui-page-segment>

### Check the project

<webui-page-segment>

This block checks that the Rust code in `src-tauri` compiles on this machine. The first run downloads and builds the dependencies, so it can take several minutes. Each block runs as its own script, so this block also adds Cargo's bin folder to PATH before it runs `cargo`.

```pwsh
$ErrorActionPreference = 'Stop'

$cargoBin = Join-Path (Join-Path $HOME '.cargo') 'bin'
if (-not (($env:PATH -split [System.IO.Path]::PathSeparator) -contains $cargoBin)) {
    $env:PATH = "$cargoBin$([System.IO.Path]::PathSeparator)$env:PATH"
}

cargo check --manifest-path src-tauri/Cargo.toml
```

If the check passes, the project is ready for development. If it fails on a missing system library, install the package named in the error and run this block again.

</webui-page-segment>

### Check the tools

<webui-page-segment>

This block lists each tool that Publish needs and reports any that are missing. ffmpeg is optional, and is only needed for the website media. Each block runs in Task Proxy's PATH, so if a tool was installed in this session but is reported missing, open a new terminal and run this block again.

```pwsh
$cargoBin = Join-Path (Join-Path $HOME '.cargo') 'bin'
if (-not (($env:PATH -split [System.IO.Path]::PathSeparator) -contains $cargoBin)) {
    $env:PATH = "$cargoBin$([System.IO.Path]::PathSeparator)$env:PATH"
}
foreach ($folder in '/opt/homebrew/bin', '/opt/homebrew/opt/node@22/bin', '/usr/local/bin') {
    if ((Test-Path $folder) -and -not (($env:PATH -split [System.IO.Path]::PathSeparator) -contains $folder)) {
        $env:PATH = "$folder$([System.IO.Path]::PathSeparator)$env:PATH"
    }
}

$required = 'pwsh', 'rustup', 'cargo', 'trunk', 'cargo-tauri', 'node', 'npm', 'npx'
$missing = @()
foreach ($tool in $required + 'ffmpeg') {
    $found = Get-Command $tool -ErrorAction SilentlyContinue
    $label = if ($tool -eq 'ffmpeg') { 'ffmpeg (optional)' } else { $tool }
    if ($found) { Write-Host "$label`: found at $($found.Source)" }
    else {
        Write-Host "$label`: missing"
        if ($tool -ne 'ffmpeg') { $missing += $tool }
    }
}
if ($missing) { throw "Missing tools: $($missing -join ', '). Run the install block for each one, then run this block again." }
Write-Host 'Every tool Publish needs is installed.'
```
